Module 06

扩展、练习与常见误解

从定位代码进阶到设计修改与验证方案。

扩展数据集

实现DatasetAdapter，注册到DataRegistry，并覆盖清单、事件和时间泄漏测试。

扩展门控指标

同时修改指标、EpisodeEvaluation差值、跨情景聚合、门控配置与测试。

递进练习

  1. 定位evaluation-only阻断提交的位置。
  2. 追踪CLI到MetaGateDecision的中间对象。
  3. 设计证据精确率下降约束。
  4. 列出接受、特化、负迁移和恢复测试。

常见误解

DEMSE不是MAML；meta-test不生成候选；Mock增益不是模型性能；当前代码不是多模态检测器。

完成标准

能定位、解释、追踪、设计扩展，并为改动选择正确测试。
