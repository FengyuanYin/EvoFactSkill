# Dataset policy

No third-party dataset is stored here. Configure authorized read-only roots in a local YAML file. Generated manifests may be saved under `data/manifests/`; raw data, derived copies and labels must not be committed.

Adapters support Weibo21, AMTCele, LiveFact and AdvFake. Always run inspection and leakage validation before an experiment, and archive the manifest ID with every result.
